# Changelog

All notable changes to Fabric Notebook Viewer are documented here.

## 0.1.1 - 2026-08-22

- Add native notebook viewing and round-trip editing for Microsoft Fabric `notebook-content.py` files.
- Add native notebook viewing and round-trip editing for Azure Synapse notebook JSON files.
- Preserve source formatting and notebook properties that the viewer does not interpret.
- Detect cell languages from Fabric and Synapse magic commands.
